RESET STUDIO - TEAM UPLOAD INSTRUCTIONS

We have created two folders for you to drop the team's assets:

1. PORTRAITS:
   - Path: `/public/assets/team/portraits/`
   - These are the circular cutouts of the team members' faces.
   - You can upload them in PNG, JPG, or SVG format!
   - Recommended names:
     - `lara.png`  (or .svg / .jpg)
     - `mayra.png` (or .svg / .jpg)
     - `tomy.png`  (or .svg / .jpg)
     - `cami.png`  (or .svg / .jpg)
     - `caro.png`  (or .svg / .jpg)

2. BADGES / BACKGROUNDS:
   - Path: `/public/assets/team/badges/`
   - These are the stylized background shapes behind each face (e.g. stars, stamps, flowers).
   - You can upload these as PNG, JPG, or SVG (SVG is highly recommended for sharp vectors)!
   - Recommended names:
     - `lara-badge.svg`  (or .png / .jpg)
     - `mayra-badge.svg` (or .png / .jpg)
     - `tomy-badge.svg`  (or .png / .jpg)
     - `cami-badge.svg`  (or .png / .jpg)
     - `caro-badge.svg`  (or .png / .jpg)

---
HOW TO UPLOAD:
1. Look at the file explorer in the left sidebar of your AI Studio interface.
2. Expand `public` -> `assets` -> `team`.
3. Right-click the `portraits` or `badges` folder and choose "Upload File", or simply drag-and-drop your images directly into them!
4. The code is already prepared to automatically load these files. No extra coding is needed once you upload them!
